# Carnicería VALCRI — Fase 1
Navbar + Hero. Estilo B aprobado. React + Vite.

## Cómo iniciar
1. Abrir esta carpeta en VS Code.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev`.
4. Abrir la URL local que indique Vite.

## Alcance
El buscador se puede abrir, y el menú móvil funciona. Los enlaces de productos, cuenta y carrito son preparatorios: se implementarán en las siguientes fases. La imagen de carne es un recorte de la maqueta aprobada, para reemplazar después por una fotografía original de alta calidad.
